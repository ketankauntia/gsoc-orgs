# 150-Topic GSoC Editorial Roadmap

This roadmap was planned after the research in [`../research/search-demand-map.md`](../research/search-demand-map.md), [`../research/gsoc-source-map.md`](../research/gsoc-source-map.md), and [`../research/seo-content-playbook.md`](../research/seo-content-playbook.md). It was last reviewed on **2026-08-12**.

These are 150 demonstrated or strongly implied search intents, not 150 pages approved for automatic publication. `Merge` items are valuable questions that belong inside a stronger canonical page. `Research` items need additional evidence before publication. `Batch 01` identifies the first 15 new articles. Organization-specific guides require current first-party maintenance capacity.

## Status legend

- **Existing:** already has a canonical published article.
- **Batch 01:** approved for the first production batch after this plan.
- **Backlog:** distinct potential article; run the publication gate before drafting.
- **Merge:** searched question that should be answered inside the named canonical page.
- **Research:** promising, but original evidence or ongoing source maintenance is not yet sufficient.
- **Annual:** page or major section that must be refreshed when official yearly facts change.
